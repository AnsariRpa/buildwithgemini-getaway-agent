# My agent: getaway-agent
One-liner: A conversational agent that helps busy travelers discover, plan, and budget weekend getaways with a catalog of destinations, itineraries, and experiences.

Tool coverage:
- Memory: Remembers home city/airport, travel preferences (pace, vibe, budget), dietary restrictions, and past/saved trips.
- Tools: Look up destination getaways by drive time or budget, fetch activity/weather recommendations, and save itineraries.
- Catalog/UI: Curated destinations, day-by-day itinerary schedules, and activity/lodging comparison tables rendered as cards/tables.
- Image gen: Generates scenic destination previews, getaway mood boards, and custom itinerary banner visuals.
- Sandbox: Trip budget breakdown and split-cost calculations for weekend groups.

Recommended for every project: memory, storage, tools, image generation, A2UI
Agent-specific / stretch (pick what fits): code sandbox for trip budgeting, live external APIs (weather/places), Cloud Trace
